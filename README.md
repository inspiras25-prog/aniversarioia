# Dia de Mimo

Site de aniversários, ideias de presente e mensagens para WhatsApp.

## GitHub
Descompacte este ZIP e envie os arquivos e a pasta assets para a raiz do repositório. index.html deve ficar na raiz, ao lado de site.css e site.js.

## Cloudflare Pages
Conecte o repositório GitHub e escolha a branch main.
- Framework preset: None
- Build command: exit 0
- Build output directory: .

Não é necessário instalar dependências ou executar compilação.

## Funcionamento
As datas cadastradas ficam no armazenamento local do navegador de cada visitante. Não há sincronização entre aparelhos. Ao mudar o endereço do site, os dados do endereço anterior não são transferidos automaticamente.
Esta versão não inclui pagamento, encomenda ou envio automático de WhatsApp. As ideias ajudam na escolha dos presentes; as mensagens podem ser abertas no WhatsApp pelo visitante.

## Alterações
index.html: estrutura e textos.
site.css: cores e aparência.
site.js: agenda, mensagens e interações.
assets/: imagens e marca.
